# Create and manage clients

**Who:** Administrators and managers can create clients. The directory's **Edit**, **Delete**, and **Links** actions are shown to administrators.

A client is the workspace that holds an organization's or person's documents. Create the workspace before assigning users to it.

## Create a client

1. Open **Clients** → **New Client**.
2. Enter a recognizable name, such as `Willow Creek Holdings`.
3. If you want to share immediately and you are an administrator, enable secure-link generation and select its access, expiry, and email options.
4. Submit the form.

The client appears in **Client Directory** with its own root folder. If link creation fails after the client is created, use that existing client's **Links** action to try again; do not create a duplicate client.

## Find and open a client

Use **Search clients...** to narrow the directory. Use the page controls when the list spans multiple pages. Select the client name or **View Files** to open its files.

The dropdown beside **View Files** contains actions such as **View Users**, **Add User**, and, for administrators, **Links**, **Edit**, and **Delete**.

## Edit a client

1. Open the client's action dropdown and select **Edit**.
2. Change the name and save.
3. Confirm the updated name in the directory.

Renaming the client is different from changing a user's name or email. Manage those from **Users**.

## Delete a client

Open the client's action dropdown, select **Delete**, and read the confirmation before proceeding. Client deletion removes the workspace and its associated data, including files. Download anything you need to retain first.

::: warning Deletion is not an access toggle
To stop a particular recipient's access while keeping documents, manage their user assignment or revoke their secure link instead. The app does not provide a trash/recovery workflow for deleted client workspaces.
:::
