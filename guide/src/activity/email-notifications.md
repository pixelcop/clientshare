# Understand email notifications

**Who:** All users receiving portal email; staff reviewing pending upload notifications.

ClientShare sends emails for account invitations, password resets, secure links, and document notifications. The exact sender and delivery behavior depend on the portal's email setup.

## Upload notifications

When staff upload files, **Notify client by email after upload** controls the optional client notification where shown. Upload emails can be queued and grouped so a batch of documents does not produce a separate immediate message for each file.

A successful upload and delivery of its notification are separate events. Confirm the file list if someone is waiting for a document.

## Review pending email for a client

Administrators and managers can open the pending-email indicator in the client workspace when messages are queued.

1. Select the envelope indicator or **View pending email**.
2. Review the recipient, subject, message preview, and scheduled time.
3. Correct the recipient or subject if necessary.
4. Select **Send now** to send the message without waiting, or close the dialog to leave it scheduled.

The scheduled time can move when more files are added. **Refresh** reloads the queue.

## Review the portal queue

Administrators can open **Settings** → **Email notifications** to see pending recipients, subjects, scheduled times, and queue times. Use **Refresh** to update the list and **Send now** to process pending notifications.

An empty queue means no messages are waiting there; it does not prove that an earlier message arrived in someone's inbox.

## If email is missing

- Verify the recipient address and check spam or junk folders.
- For upload notifications, check whether notification was selected and whether the email is still queued.
- For invitations, use **Users** → **Resend Invite** for the intended person.
- For reset emails, request a new reset from the sign-in page.
- If delivery keeps failing, ask the portal operator to check email configuration and delivery logs.

Avoid sending repeated invitations before confirming the address. A copied invite or secure link can be delivered directly to the intended recipient when appropriate.
