# Send and receive documents

**Who:** Client users and secure-link recipients.

Open your organization's portal and sign in, or follow the secure link the sender gave you. Check the client name before uploading or downloading.

## Send documents

1. Open the destination folder the sender asked you to use.
2. Drag files into the upload area, or select files with the picker.
3. If asked to rename duplicate files, give each one a distinct name and continue.
4. Wait until the upload finishes.
5. Check that the uploaded filenames appear in the list.

You can select multiple files. For a large batch, keep the page open until every transfer has finished. If an error appears, check which files arrived before trying again.

No upload area? You may have a **Read-only** link. Ask the sender for upload access.

## Receive documents

1. Open the relevant folder.
2. Select a filename or **Preview** to view it.
3. Select the download icon to save a copy to your device.
4. Use a folder's download icon to download its contents as a ZIP when available.

If a file cannot be previewed, download it and open it in the appropriate application. With **Upload-only** access, downloading is intentionally unavailable.

## Correct an upload

Client users and link recipients do not have staff deletion controls. Contact the sender with the folder and filename if you uploaded the wrong document. If sending a replacement, use a clear name such as `Project brief - corrected.pdf` and tell the sender which version to use.

## When you are finished

Confirm that the files are listed before closing the page. Sign out if you are using an account on a shared device. If the sender asked for confirmation or more information, reply through your usual communication channel.

For access, expiry, and transfer problems, see [Troubleshooting](../help/troubleshooting.md).
