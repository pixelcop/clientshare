# Glossary

| Term | Meaning |
| --- | --- |
| **Portal** | Your organization's ClientShare site, where people exchange documents. |
| **Client** | A workspace containing files and folders for a person or organization. |
| **User** | A person with an account that can sign in to the portal. |
| **Admin** | A staff role with portal settings and secure-link management access. |
| **Manager** | A staff role that works with clients, users, and documents. |
| **Customer / client user** | An account restricted to its assigned client workspaces. |
| **Client assignment** | The connection allowing a client user to access a particular workspace. |
| **Root folder** | The top-level folder in a client's workspace. |
| **Breadcrumb** | The navigation path showing the current folder and its parents. |
| **Secure link** | A client-wide access URL with specified permissions and an expiry. |
| **Read** | Link permission to view and download documents. |
| **Write** | Link permission to upload documents; downloads are disabled. |
| **Read & Write** | Link permission to view, download, and upload documents. |
| **Expiry** | The time after which a secure link is no longer usable. |
| **Revoke** | End a link's access before or regardless of its scheduled expiry. |
| **Invitation** | An email/link that lets a new user set up account access. |
| **Passkey** | A sign-in credential used through a device lock, biometric verification, or security key. |
| **Activity** | The account's unread/read event notifications. |
| **Pending email** | A queued notification waiting to be sent. |
| **Public base URL** | The portal address used to generate links in a single-tenant deployment. |

For a practical comparison of roles and links, see [Roles and access](../getting-started/roles-and-access.md).
