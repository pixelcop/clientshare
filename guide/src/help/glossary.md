# Glossary

| Term | Meaning |
| --- | --- |
| **Portal** | Your organization's ClientShare site, where people exchange documents. |
| **Client** | A workspace containing files and folders for a person or organization. |
| **User** | A person with an account that can sign in to the portal. |
| **Administrator** | An Internal organization role that manages the portal and has access to all client workspaces. |
| **Member** | An Internal organization role; document access requires assignments or explicit all-workspace access. |
| **Internal / External** | A person's identity type: team member or outside contact. Not a document permission. |
| **Access role** | An editable set of document permissions assigned at a workspace, folder or file. |
| **Client user** | Someone who signs in to the workspaces, files or folders shared with their account. |
| **Client assignment** | The connection allowing a client user to access a particular workspace. |
| **Root folder** | The top-level folder in a client's workspace. |
| **Breadcrumb** | The navigation path showing the current folder and its parents. |
| **Secure link** | A link anyone who has it can use, with permissions and an expiry chosen by the sender. |
| **Direct share** | A file or folder shared with a person's account, without sharing the whole client. |
| **Inherited access** | Access to a file because its client or a containing folder was shared with you. |
| **Shared with me** | The page where you find files and folders shared with your account. |
| **View & download / Read-only** | Link permission to view and download documents. |
| **Upload only / Upload-only** | Link permission to upload documents without seeing existing files or folders. |
| **View, download & upload / Read & upload** | Link permission to view, download, and upload documents. |
| **Expiry** | The time after which a secure link or time-limited item assignment stops granting access. |
| **Revoke** | End a link's access before or regardless of its scheduled expiry. |
| **Invitation** | An email/link that lets someone accept shared access, setting up an account if needed. |
| **Passkey** | A sign-in credential used through a device lock, biometric verification, or security key. |
| **Activity** | The account's unread/read event notifications. |
| **Pending email** | A queued notification waiting to be sent. |
| **Public base URL** | The portal address used to generate links in a single-tenant deployment. |

For a practical comparison of roles and links, see [Roles and access](../getting-started/roles-and-access.md).
