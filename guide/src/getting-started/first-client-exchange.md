# Your first client exchange

**Who:** Administrator. Managers can create clients, invite users, and work with files, but secure-link management requires an administrator.

This walkthrough takes a fictional client, **Willow Creek Holdings**, from an empty workspace to a two-way document exchange.

## 1. Create the client

1. Open **Clients** and select **New Client**.
2. Enter the client name.
3. If the form offers to generate a secure link, leave that option off for now.
4. Create the client.

The client appears in the directory with a **View Files** action. See [Manage clients](../clients/manage-clients.md) for editing and deletion.

## 2. Add a folder and document

1. Select the client's name or **View Files**.
2. Create a folder with **New Folder**, for example `Getting Started`.
3. Open the folder and drop a document into the upload area, or use the file picker.
4. Wait for the upload to finish and check that the file is listed.

Try [previewing the file](../files/preview-and-download.md) before sharing it.

## 3. Share access

1. Return to **Clients**.
2. Open the dropdown beside **View Files** and select **Links**.
3. Create a secure link with **Read & Write** access and an expiry appropriate for the exchange.
4. Send it by email, or turn off **Send link by email** and copy the generated link.

The recipient can view, download, and upload within this client's workspace. For ongoing access through a named account, [invite a client user](../clients/manage-users.md) instead.

::: tip Check the scope
A secure link applies to the client workspace, not just the folder you last opened. Use a client workspace that contains only the material intended for that recipient.
:::

## 4. Collect the response

Ask the recipient to open the link and upload their document. They do not need to create an account to use the link. You can send them the [client document guide](../for-clients/send-and-receive-documents.md).

Return to the client's files to confirm that the document arrived. Review **Activity** for available notifications. If you only need to collect files, use a [Write link](../sharing/request-documents.md) instead of Read & Write.

## 5. Finish the exchange

Once the exchange is complete, [revoke the link](../sharing/manage-links.md) if access is no longer needed. Revoking a link stops that link's access; it does not remove copies someone has already downloaded or remove their separate user account.
