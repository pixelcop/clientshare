# Preview and download files

**Who:** Staff, assigned client users, and recipients with Read or Read & Write access.

## Preview a document

1. Open the client workspace and find the file.
2. Select the filename or choose **Preview** from its actions.
3. Use the viewer's available controls to inspect the document.
4. Return to the file list when finished.

Preview behavior depends on the file type and browser. The app has viewers for PDFs, images, text, and audio; a file without a supported preview can be downloaded and opened in an appropriate application.

## Download a file

Select the download action on the file's row. Staff see a main download button with an action dropdown; client recipients see a download icon alongside **Preview**.

Your browser saves the file according to its download settings. Check its downloads list if you do not see the file immediately.

## Download a folder as ZIP

Use **Download Zip** from the folder actions, or the folder's download icon where shown. Open the downloaded ZIP on your device to access its contents. Large folders may take longer to prepare.

## When a preview or download is unavailable

- **Uploads only:** the link does not allow reading or downloading documents. Ask the sender for read access if needed.
- **Unsupported preview:** download the file and open it locally.
- **Missing file or access error:** return to the workspace and refresh; the file may have been removed or your access may have changed.
- **Expired link:** ask the sender for a replacement link.

Downloading creates a copy on your device. Later changes to the portal document or link do not update or remove that copy.
