# Delete files and folders

**Who:** Administrators and managers.

Use deletion to remove documents that should no longer be stored in the client's workspace. To stop sharing while retaining the documents, [revoke the relevant link](../sharing/manage-links.md) or change a user's assignment instead.

## Delete an item

1. Open the correct client workspace and folder.
2. Open the action dropdown for the file or folder.
3. Select **Delete**.
4. Check the name in the confirmation and confirm only when it is the intended item.
5. Confirm that it no longer appears in the file list.

::: warning Download what you need first
Deleting a folder removes it from normal navigation, including the route to its contents. The app does not offer an undo or trash view for restoring deleted items. Keep any needed copy before confirming.
:::

## What deletion does not do

Deleting a document does not remove copies that recipients have already downloaded. Deleting a folder is not the same as deleting the client workspace, and deleting a file does not revoke the client's other secure links.

## If Delete is missing

Client users and secure-link recipients do not get the staff deletion controls, even when they can upload. Ask the portal staff to remove an incorrect upload and tell them the client, folder, and filename.
