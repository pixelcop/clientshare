# Request documents from a client

**Who:** Administrators. Managers can ask an administrator to create a link or invite a client user for ongoing exchanges.

Use a **Write** secure link when you want a recipient to send documents without downloading material from the workspace.

## Prepare the request

1. Open or [create the client workspace](../clients/manage-clients.md).
2. Organize any destination folders you need.
3. List the documents you want in your message, using names the recipient will recognize.

For example, ask for a project brief, an asset inventory, and supporting images. Explain your deadline and which folder to use if needed.

## Send an upload link

1. Open the client's **Links** action and choose **New Link**.
2. Set **Access Type** to **Write**.
3. Set the expiry to cover the requested submission period.
4. Email the link or clear **Send link by email** and copy it into your own message.

You can include the [recipient instructions](../for-clients/send-and-receive-documents.md) in your message.

## What the recipient sees

The secure-link page identifies the client and shows **Upload-only** access with an expiry. The recipient uploads through the drop area. Downloads are disabled, and creating a permanent account is not required to use the link.

## Confirm receipt

Open the client workspace and check that the requested files are present. Review available **Activity** notifications and inspect the documents as needed. If something is missing, follow up with the recipient using your usual communication channel.

This workflow uses secure links and the file list; it does not create a separate checklist with per-document request statuses. Keep your request list in your message or your team's existing task system.

When collection is finished, [revoke the link](./manage-links.md) if it is no longer needed.
