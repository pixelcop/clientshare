# Create and send a secure link

**Who:** Administrators.

A secure link lets a recipient exchange documents without first creating a user account. Decide which client workspace to share and what the recipient should be able to do before generating it.

## Create the link

1. Open **Clients**.
2. Open the dropdown beside the client's **View Files** button and choose **Links**.
3. Select **New Link**.
4. Choose **Access Type**: **Read**, **Write**, or **Read & Write**.
5. Select or enter **Expiry (days)**, from 1 to 120.
6. To email the link, leave **Send link by email** selected and enter the recipient's address. To share it yourself, clear the checkbox.
7. Select **Create Link**.

The new link appears in the client's **Secure Links** list. You can also generate a link while creating a new client.

::: important Review the entire workspace
The link applies to the client, including its folders. It is not restricted to the file or folder you last opened. Check that the workspace is appropriate for the recipient.
:::

## Copy and share

Select **Copy** on the link's row. When the button reads **Copied**, paste it into your message to the intended recipient. The generated-date text in the link column also copies the link.

Include the purpose of the exchange, the documents you need, and the deadline. For example: “Please upload your project brief and supporting images using this link by Friday.”

If copying fails, allow clipboard access in your browser and try again. If the URL is unavailable, refresh the page before retrying.

## Check the result

Confirm the **Access** and **Expires** columns before sending. The form remembers recent link options in your browser, so check them for each new recipient.
